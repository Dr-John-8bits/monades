# Mutable Dreams 1.0

*Six voices. Small worlds, endlessly unfolding.*

An independent generative instrument for the **M-VAVE FM-1**, with a fully playable browser synth and patch editor. Created by **Kid Bunka**, with gratitude to Émilie Gillet and Mutable Instruments.

- Six freely assignable tracks across eight sound engines.
- 64 editable Biomes plus Blank, and 128 sound presets.
- Selected original Plaits algorithms and the Rings modal resonator; our own Choir and granular bus.
- Euclidean rhythms, probability, swing, accents, repeats and shared musical scales.
- Per-track filters, envelopes and granular sends; four live macros and held-button help.
- Browser patch import/export, local SAVE, tutorial and USB installer.
