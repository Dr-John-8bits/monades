MIDI

Brancher le FM-1 à d'autres machines (MPC, MS-20, S-1, ordinateur…) : le jouer, envoyer ses notes, partager le tempo. Chaque réglage MIDI en détail : le mode d'emploi.

§1Prises

Les prises MIDI du FM-1

  • USB : MIDI dans les deux sens (notes, CC, horloge), et l'audio vers l'ordinateur. Branché, le FM-1 apparaît sous le nom « Monades FM-1 ».
  • TRS MIDI IN : une entrée seulement (notes, CC, horloge).
  • Pas de prise MIDI OUT : tout ce que le FM-1 envoie passe par l'USB. Pas de Bluetooth MIDI dans ce firmware.

Faire jouer une autre machine (MS-20, S-1, MPC…)

Le FM-1 est un appareil USB : deux appareils USB branchés l'un sur l'autre ne se parlent pas. Il faut un hôte USB entre les deux :

  • un ordinateur, qui fait suivre le MIDI du FM-1 vers l'autre machine ;
  • une machine qui est elle-même hôte USB, comme une MPC ;
  • un boîtier hôte USB-MIDI, qui ressort le MIDI du FM-1 sur des prises MIDI (5 broches ou TRS) vers l'entrée MIDI de la machine.

Faire jouer le FM-1 par une autre machine

  • Une machine avec une sortie MIDI (5 broches ou TRS) : dans la prise TRS MIDI IN du FM-1, avec l'adaptateur qui convient.
  • Une machine ou un ordinateur hôte USB : par le câble USB.
§2Réglages

Jouer, enregistrer, partager le tempo

  1. Jouer le FM-1 depuis une autre machine. Par défaut, canaux 1 à 6 = pistes 1 à 6, avec vélocité et pitch bend ; GLO › MIDI CHANNELS change le canal de chaque piste (par exemple pour laisser les canaux 1 et 2 à d'autres machines). CC 7 niveau, 10 pan, 74 filtre, 71 résonance, 91 envoi room, 12 envoi écho, 13 envoi grain, 5 glide, 11 expression, 64 sustain ; un changement de programme choisit le son. Sur le canal 16, les CC 16 à 19 pilotent les quatre macros de LIVE (Density, Motion, Colour, Space). GLO › MIDI, K2 : ramène les notes reçues dans la gamme.
  2. Envoyer les notes générées (à un séquenceur, une MPC, un synthé). GLO › MIDI, K3 NOTES OUT :
    TRACKS : chaque piste sort sur son canal (GLO › MIDI CHANNELS, K3 ; par défaut la piste n sur le canal n).
    ZONES : chaque plage de notes sort sur son canal. Réglage sur GLO › MIDI OUT ZONES : K1 zone (8), K2 note basse, K3 note haute, K4 canal (OFF ou 1 à 16). Une note dans deux zones part sur les deux canaux.
    Par défaut :
    C1 → B2  ·  canal 1
    C3 → B4  ·  canal 2
    C5 → C7  ·  canal 3
    Les notes reçues en MIDI ne sont jamais renvoyées.
  3. Le tempo. Le FM-1 mène : K4 CLOCK OUT sur ON (horloge MIDI par l'USB, start et stop avec PLAY), et l'autre machine suit l'horloge reçue. L'autre machine mène : K1 CLOCK IN sur USB ou TRS ; l'horloge envoyée se coupe alors.
  4. Gammes microtonales. En TRACKS, chaque note part avec un pitch bend : régler la plage de bend de l'instrument sur ±2 demi-tons. En ZONES, les notes sont arrondies au demi-ton.
  5. Garder les réglages. SAVE, à l'arrêt.

Les ornements (gamakas) ne sont pas envoyés en MIDI : l'autre machine reçoit la note sans le glissé.
