assignable tracks, mixer, granular, shared echo/room, 16-step note/rest phrases,

the new one. Mallet/Plectrum/Particles are now named directly in SOUND.

external clock, consistent with bank writes. Marbles help states EUCLID/STEP.

contour trails and tapered mixer reservoirs. Extra RAM 1680 B, code 1240 B
over e59b; no extra framebuffer, audio buffer or higher frame-rate target.

REMAINING RELEASE WORK — EXPLICIT LIMITS
Owner listening on headphones/speakers, extended cold/power-cycle sessions,
physical TRS MIDI cabling, longer MIDI/jitter tests, and exact stock V15 ->
final release -> V15 -> release installation/recovery qualification remain.
No claim that arbitrary six-track parameter combinations or all firmware paths
are certified by a finite stress matrix. ECO reconstructs FM/VA/Harmonic at half
rate; Elements shares a mode budget; granular memory remains mono PCM16.
Full hardware-bank restore/import and live browser-to-device editing are not
implemented. Browser-local banks and individual JSON import/export work, but
are independent of hardware. LIVE still shows the factory-origin Biome name;
custom names are visible in BANKS. Dedicated copy/delete is unfinished.
No MPE, MIDI OUT, live MIDI recording, ties/per-step velocity or 64-step arranger.
Marbles/Tides/Warps are inspired functions, Elements a selected subset. CPU2
stays disabled until its own coherency/flash/deadline qualification is complete.
The platform backup/restore tests passed separately; that is not app integration.
