Elements Strike is a reduced port of the original Elements Exciter and Resonator, retaining Emilie Gillet MIT notices. Mallet, plectrum and particles are selectable by SHAPE. The original bowed waveguide bank, Bow/Blow performance layer, internal reverb, string alternatives and Ominous voice are not included. Resonator allocation is retained in regular RAM rather than the audio pool. 16 modes FULL / 8 ECO, both at 44.1 kHz. These are provisional profiles, not hardware-qualified limits. All slots remain assignable. The percussive exciter tables were designed for the original 32 kHz module: this port is not bit-identical to the original sound. See device-build and offline test logs; no hardware test performed.

24 October revision: block-interpolated pickup weights and a shared 16-mode budget for multiple Elements voices, including ECO. See 1.1-MELLOW-CHECKPOINT.txt; new hardware qualification is pending.
