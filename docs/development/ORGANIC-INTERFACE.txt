ORGANIC INTERFACE — 25 OCTOBER 2026
Implemented in response to the request for a more living, translucent interface.

- Asymmetric leaf-shaped control panels blend with the actual background under
  them (RGB565, 12/32 panel tint). The contour remains visible through the panel.
- Curved twig sliders with small leaf ticks and a bright bud mark the exact value.
  The slider start adapts to number width, including five-digit frequency values.
- Seven soft moving shoots with fading trails follow cached page contours,
  including beneath the control cards. Subpixel coverage smooths their travel.
- Mixer reservoirs have rounded, tapered leaf ends and a central vein. Fill
  height still follows track level; adjacent meters show measured sound activity.
- Quiet text backplates, high-contrast values and the rasterized Nunito font
  preserve readability. Help remains opaque. Mallet/Plectrum/Particles have
  direct labels; Marbles help now states the EUCLID/STEP phrase requirement.

No additional framebuffer, audio callback work, DSP voice, delay memory, dynamic
allocation or higher refresh-rate target was added. The flow table uses 1,680
additional bytes of ordinary RAM. Rendering still targets one frame per 80 ms.
Alpha blending and trails do add foreground drawing work; hardware stress is
therefore required, rather than claiming that animation is computationally free.
The LCD remains 240 x 240 pixels. Preview GIF scaling does not add panel pixels.

Native tests used the same firmware UI with AddressSanitizer/UBSan. All 266
page/key help contexts passed. STILL-mode screenshots one second apart were
pixel-identical. The source produces the provided screenshots and motion GIF;
these are not design mockups or images generated by AI. Local-file browser
automation remained blocked; no alternate local browser route was used.

See DEVICE-TEST-REPORT.txt for the final hardware build hash and graphic/audio
stress evidence. Source and local browser instrument are updated together.
