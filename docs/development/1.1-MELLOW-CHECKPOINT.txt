MUTABLE DREAMS 1.1 — MELLOW DEVELOPMENT CHECKPOINT
25 October 2026. Not a release. Published 1.0 and the developer handoff ZIP are unchanged.

Implemented
- Elements pickup weights interpolated once per block instead of rebuilding two
  cosine oscillators per sample. In addition to the FULL-to-ECO guard, multiple
  Elements slots share 16 modes: 2 slots / 8 each, 3 / 5, 4 / 4, 5 / 3, 6 / 2.
  A single slot keeps 16 FULL / 8 ECO. No track is silenced. This changes timbre
  in dense patches and is not a measured hardware-performance guarantee.
- Mellow Drift: two gently drifting sine oscillators, finite odd harmonics for a
  triangle-like contour, mild second harmonic. No new delay buffers, no global EQ.
- 64 additional presets (IDs 160–223): Mellow, Velvet Bass, Hearth VA and Satin.
  Twelve new musical Biomes (65–76). Existing IDs and Blank (64) stay in place.
  Totals: 12 engines, 224 sounds, 76 musical Biomes plus Blank, six mono tracks.
- Original Satin Morph: interpolated, band-limited sine/triangle/reed/rounded-saw
  tables, gentle drift and smooth spectral controls. No additional delay memory.
- Named banks: 16 user Biomes, 64 user tones. GLO cycles to USER BANKS. K1 slot,
  K2 Biome/Tone, K3 right loads, K4 name cursor, PRESET changes its character.
  SAVE writes explicitly while stopped and in internal-clock mode; existing slots
  require a second press within three seconds. Names: up to 23 ASCII characters.
  Tone recall preserves rhythm, note, levels and sends. Biomes preserve full patch.
  Browser has the same banks, name field and file export/import; browser storage
  is independent of the physical device. Direct browser-to-device patch transfer
  is not implemented. Export files before clearing browser data.
- Sequence mode OFF / EUCLID / STEP: STEP plays the editable 16-note/rest phrase
  without hidden Euclidean hit gating. Length uses 1–16 steps in STEP mode (longer
  Rhythm lengths are clamped for this mode); scale, probability, repeats, accent,
  clock division and six independent phrases remain available. Per-step velocity,
  gate, ties, realtime recording, 32/64 steps and chaining are not implemented.
- MIDI input, at most 16 packets per audio block: channels 1–6, exact notes 24–96
  by default, optional scale snap; monophonic last-note priority. Velocity,
  melodic note-off / velocity-zero off, sustain, smoothed +/-2-semitone bend,
  expression, CC7 level, CC10 pan, CC74 cutoff, CC71 resonance, CC5 glide,
  CC91 room, custom CC12 delay / CC13 grain. CC120 silence, CC123 release,
  CC121 reset performance controls. Bank MSB (CC0) + Program selects factory
  tones (bank*128+program); LSB is reserved/ignored. Channel 16 CC16–19 macros.
  USB or TRS external 24-PPQN clock, Start/Continue/Stop, approximate smoothed
  tempo tracking and two-second clock-loss stop. INT is default. MIDI settings
  are session settings, not saved in a patch. No MPE, MIDI output, Song Position
  Pointer, realtime record/overdub or live-device editor protocol is claimed.
  Repeated held notes do not form a polyphonic stack. A 20-second, 10,800-message
  USB flood passed on the device; longer floods, real-clock jitter and physical
  TRS cabling still need qualification.
- Rounded control cards, page-specific organic contours/ferns, slow margin pollen
  and subpixel live blooms using cached geometry;
  motion-off still works, long-hold help remains separate from short actions.

Patch and storage
Current patch version is 6, size still 1292 bytes. v5 is imported without changing
its fields; v1–v4 migrations remain. Older firmware does not accept new v6 patches.
Bank objects append to IDs 0–2 (unchanged): 16 Biome pairs at 0x98000..0xB7FFF and
four packed tone pairs at 0xB8000..0xBFFFF. Mutable Dreams uses no sample banks.
Existing patch/panel/preferences, updater staging and calibration regions remain
separate. Do not interpret this as migration of another firmware's sample data.

Validation completed
Native address/undefined-behavior sanitized feature tests, full DSP catalogue/
stress tests, granular window sweep, actual WASM worklet, 19 pages, patch roundtrip,
legacy import, invalid-patch rejection, user bank recall/overwrite/reboot and
64 new warm presets; hardware UI simulator checks including long holds.
Real storage algorithm tested against simulated NOR with interruption injection
across all 20 new bank objects; committed payload survives tested interruptions.
Three 24-second WAV examples are offline renders, not device recordings.
See current logs in docs/development/mellow-validation; earlier logs elsewhere
refer to earlier candidates and must not be treated as current qualification.

Performance work: Elements/Rings pickup work per tile, unchanged-coefficient
