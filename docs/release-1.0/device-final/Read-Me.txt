These results were measured on the physical M-VAVE FM-1 running the exact Mutable Dreams 1.0 package, identified by SHA-256 in every summary. Device control uses the remote panel/diagnostic paths over USB-MIDI. Audio is taken explicitly from the Mutable Dreams USB interface, never from a microphone. The six-step performance suite is followed by same-version save/pref persistence, a 1.0-to-V15-to-1.0 return cycle and final saved-state verification. Private user backups are deliberately omitted. Earlier native/sanitizer comparisons remain under their original identifiers in docs/release-evidence.
